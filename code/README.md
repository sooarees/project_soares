# Como rodar o jogo

1. Abra o **Qt Creator**.
2. Selecione **File > Open File or Project**.
3. Abra o arquivo `CMakeLists.txt` desta pasta `code`.
4. Escolha um kit com **Qt 6** e **MinGW 64-bit**.
5. Aguarde o CMake configurar o projeto.
6. Clique em **Build** para compilar.
7. Clique em **Run** para executar o jogo.

Observação: o projeto usa os módulos **Qt Widgets** e **Qt Multimedia**.
